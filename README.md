# Ананасовый улун

Верхняя часть карточки товара по тестовому заданию Teaboom.ru.
HTML5, обычный CSS, vanilla JavaScript; без сборки и зависимостей.

## Запуск

Откройте `index.html` в браузере. Установка пакетов и сервер не нужны.
Изображение и шрифты находятся в проекте; интернет для запуска не требуется.
